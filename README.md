# بازگشت ربات آوا به نسخهٔ اولیه

bot.py از کد اولیهٔ ارسالی کاربر در ابتدای همین گفتگو بازیابی شده است؛ نه از نسخه‌های میانی مشاوره و واتساپ. منطق و متن‌های قبلی حفظ شده‌اند. requirements و این راهنما و تست‌ها برای بسته‌بندی فعلی اضافه شده‌اند.

## مسیر قبلی
انتخاب زبان ← ۱۰ سؤال ← انتخاب هدف ← اشتراک شماره ← نمایش کارنامه و ارسال لید به ادمین.
نمایش نتیجه در این نسخه به ارسال شماره وابسته است. منوی واتساپ و سؤال نیت ابتدای آزمون ندارد.

## نصب روی پروژهٔ فعلی
1. از کد فعلی، متغیرهای محیطی و دیتابیس روی سرور نسخهٔ پشتیبان بگیرید. اگر SQLite در حال استفاده است، از روش پشتیبان‌گیری سازگار SQLite یا توقف سرویس پیش از کپی استفاده کنید.
2. bot.py را در پروژهٔ GitHub جایگزین کنید. برای محیط تازه، requirements.txt این بسته را نصب کنید (Python 3.10 یا جدیدتر). اگر requirements فعلی وابستگی‌های دیگری هم دارد، آن را کورکورانه جایگزین نکنید.
3. BOT_TOKEN و ADMIN_CHAT_ID فعلی را در Variables سرور نگه دارید. ADMIN_CHAT_ID آیدی عددی مقصد تلگرام است، نه شمارهٔ تلفن. ادمین باید قبلاً ربات را Start کرده باشد یا ربات به گروه مقصد دسترسی ارسال داشته باشد.
4. دستور اجرا: python bot.py
5. فقط یک نمونهٔ polling با این توکن اجرا شود. سرویس قبلی را متوقف و نسخهٔ جدید را Deploy کنید.
6. روی تلگرام موبایل /start بزنید، آزمون را تا انتها بروید، هدف را انتخاب و شمارهٔ آزمایشی خودتان را با دکمه بفرستید. نمایش کارنامه و دریافت نام، شماره، زبان، نمره و هدف در چت ادمین را بررسی کنید.
7. تا دریافت واقعی لید توسط ادمین تأیید نشده، بودجهٔ تبلیغ را افزایش ندهید.

## محدودیت‌های همان نسخهٔ قدیمی
- دیتابیس را نمی‌خواند، نمی‌نویسد و پاک نمی‌کند؛ دیتابیس فعلی را نگه دارید، اما آمار جدید در آن ثبت نخواهد شد.
- /report ندارد. نشست‌ها فقط در حافظه هستند و بعد از ری‌استارت، کاربران نیمه‌کاره باید دوباره /start بزنند.
- لید فقط با پیام تلگرام به ادمین فرستاده می‌شود. در صورت خطای ارسال، خطا در لاگ ثبت می‌شود؛ صف ذخیره یا تلاش مجدد خودکار وجود ندارد. نمایش کارنامه تضمین دریافت لید توسط ادمین نیست.
- تطبیق مالک شماره با فرستنده در کد اولیه انجام نمی‌شود.
- متن‌های قدیمی دربارهٔ «سطح دقیق/استاندارد CEFR»، «تحلیل کارشناسان»، «رزرو جلسه» و «ثبت در پنل» عیناً حفظ شده‌اند؛ بازیابی نسخه به معنی تأیید این ادعاها نیست. این کد آزمون معتبر جامع CEFR، رزرو واقعی جلسه یا ثبت در CRM انجام نمی‌دهد.
- خطاهای متنی موجود در سؤال‌های ایتالیایی ۸ و ۱۰ نیز برای حفظ نسخهٔ مبنا تغییر نکرده‌اند.
- هیچ توکن، فایل .env یا دیتابیس در بسته نیست. کد به‌صورت خودکار .env را بارگذاری نمی‌کند؛ متغیرها باید در محیط اجرا تنظیم باشند.

## بررسی
python -m unittest -v test_bot.py
python -m py_compile bot.py
تست‌ها آفلاین و با شبیه‌سازی تلگرام هستند؛ صحت استقرار، دسترسی ادمین یا ارسال واقعی پیام را ثابت نمی‌کنند.
